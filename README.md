# Sparkler Web 🔥

Sparkler is a full-stack web application built with a clean separation between frontend and backend.  
It is designed for scalability, maintainability, and modern web development practices.

---

## 📁 Project Structure

sparkler/
├── backend/ # Django backend (REST API)
├── frontend/ # React / Next.js frontend
└── README.md

---

## 🚀 Tech Stack

### Frontend

- React / Next.js
- TypeScript
- Tailwind CSS

### Backend

- Django
- Django REST Framework
- PostgreSQL / SQLite

---
